# OOW Oral Trainer

A study app for the MCA Deck Officer of the Watch (Unlimited) oral exam. Created by The Big Cheese.

**Open it:** https://jamienathaniel97.github.io/oow-oral-trainer/

- **Mock oral:** 88 examiner-style questions with model answers, plus 5- or 10-question mini tests.
- **Lights:** a quiz on night lights, day shapes and sound signals (with horn sounds).
- **Cards:** spaced-repetition flashcards.
- **Library:** searchable quick-reference tables.

Works offline once it has been opened. On Android, open the link in Chrome, then use
**⋮ → Install app** (or **Add to Home screen**). Progress is saved on the phone.

Study aid only: check anything that matters against the current official COLREGs,
SOLAS, MARPOL, STCW and MCA guidance.
